# Office PDF コンバーター インストールマニュアル

このマニュアルは、Officeファイル（PowerPoint・Word・Excel）をまとめてPDFへ変換するデスクトップアプリ「Office PDF コンバーター」の導入手順をまとめたものです。

読む場所は立場によって異なります。

- **配布されたexeを使う方**は「第1部 アプリを使うパソコンへの導入」だけをお読みください。Pythonのインストールは不要です。
- **exeを作る担当の方**は「第2部 exeを作る」をお読みください。GitHub上でビルドする方法と、手元のパソコンでビルドする方法を説明しています。

## 第1部 アプリを使うパソコンへの導入

### 1-1. 事前に確認すること

導入前に、使うパソコンが次の条件を満たしているか確認してください。

- Windows 10 または Windows 11 であること
- 変換したい形式に対応するデスクトップ版のMicrosoft Officeが導入されていること
- そのOfficeを一度起動し、サインインとライセンス認証が終わっていること

必要なOfficeは、変換したいファイルの種類ごとに次のとおりです。

- PPTXファイルを変換する場合は Microsoft PowerPoint
- DOC・DOCXファイルを変換する場合は Microsoft Word
- XLS・XLSX・XLSM・XLSBファイルを変換する場合は Microsoft Excel

本アプリはOffice本体を含んでいません。パソコンにインストール済みのOfficeを裏側で動かしてPDFを作ります。そのため、**Web版（ブラウザー版）やスマートフォン版のOfficeだけでは変換できません**。デスクトップ版が必要です。

Pythonのインストールは不要です。exeにはアプリの動作に必要なPython関連のファイルがすべて含まれています。

### 1-2. exeを置く

配布された `OfficePdfConverter.exe` を、パソコン上の書き込みできる場所へコピーします。インストーラーはありません。ファイルを置くだけで導入は完了です。

置き場所の例は次のとおりです。

- デスクトップ
- ドキュメントフォルダーの中に作った専用フォルダー（例: `ドキュメント\OfficePDF`）

ネットワーク共有フォルダーやUSBメモリーからも起動できますが、読み込みに時間がかかることがあります。動作が遅い場合はパソコン内部へコピーしてください。

デスクトップから起動したい場合は、exeを右クリックして「その他のオプションを確認」から「ショートカットの作成」を選び、作られたショートカットをデスクトップへ移動します。

### 1-3. 起動する

`OfficePdfConverter.exe` をダブルクリックします。黒いコンソール画面は表示されず、アプリの画面だけが開きます。

初回起動時は、ウイルス対策ソフトの確認のため、画面が出るまで10秒ほどかかることがあります。

### 1-4. 「WindowsによってPCが保護されました」と表示された場合

インターネットから入手した署名のないexeを初めて実行すると、SmartScreenという機能が青い画面で警告を出すことがあります。配布元が信頼できることを確認したうえで、次の手順で起動してください。

1. 青い画面の「詳細情報」をクリックします。
2. 表示された「実行」ボタンをクリックします。

この確認は最初の1回だけです。

警告が出ずにファイルがブロックされる場合は、exeを右クリックして「プロパティ」を開き、「全般」タブの下部にある「許可する」または「ブロックの解除」にチェックを入れて「OK」を押してください。

### 1-5. 動作を確認する

アプリが起動したら、画面下部の「処理結果ログ」を確認します。起動直後に、使用できるOfficeが次のように表示されます。

- 「使用できるOffice: Excel、PowerPoint、Word」のように表示されていれば、その形式は変換できます。
- 「見つからないOffice: ...」と表示された形式は変換できません。第1部1-1の条件を満たしているか確認してください。

続いて、実際に1ファイルだけ変換して確認します。

1. 「Officeファイルを選択」をクリックし、手元のファイルを1つ選びます。エクスプローラーから一覧へドラッグ＆ドロップしても追加できます。
2. 「PDFに変換」をクリックします。
3. 元のファイルと同じフォルダーに、同じ名前のPDFが作られたことを確認します。

### 1-6. アンインストール

レジストリや他のフォルダーへ書き込みは行いません。`OfficePdfConverter.exe` と、作成したショートカットを削除すれば完全に削除できます。

### 1-7. 困ったときは

#### アプリが起動しない、ダブルクリックしても何も起きない

ウイルス対策ソフトがexeを隔離していないか確認してください。社内PCでは、管理者による実行の許可が必要な場合があります。

#### 「Microsoft Officeが見つかりません」と表示される

変換に必要なデスクトップ版Officeがインストールされていないか、まだ一度も起動していない可能性があります。スタートメニューから対象のOffice（PowerPoint・Word・Excel）を起動できるか確認してください。起動できるのにこの表示が出る場合は、Officeの「クイック修復」を実行すると解消することがあります。

#### 変換に失敗する

ログに「失敗」と処理段階が表示されます。対象ファイルをOfficeで手動で開けること、クラウド同期が完了していること、保存先フォルダーへ書き込みできることを確認してください。

#### PDFが作られない、または途中で止まる

変換中はOfficeが裏側で動いています。パスワード保護されたファイルや、開いたときに確認ダイアログが出るファイルは変換できないことがあります。

## 第2部 exeを作る

配布用のexeを自分で作る場合の手順です。

### 2-1. 2つのビルド方法

exeの作り方は2通りあります。

- **GitHub Actionsでビルドする**（2-2）— GitHubのサーバーがビルドします。手元のパソコンにWindowsもPythonも必要ありません。ふだんはこちらをおすすめします。
- **手元のWindowsパソコンでビルドする**（2-3以降）— 自分のパソコンにPythonを入れてビルドします。ソースコードを書き換えながら動作を確かめたい場合はこちらです。

PyInstallerというビルドツールは、動かしているOS向けの実行ファイルしか作れません。そのためWindows用exeは、どちらの方法でも最終的にWindows上でビルドすることになります。GitHub Actionsを使う場合は、GitHubが用意したWindowsのサーバーが代わりに作業します。

### 2-2. GitHub Actionsでビルドする

リポジトリに含まれている `.github/workflows/build-exe.yml` が、GitHub上でexeを組み立てる手順書です。ボタンを押すだけで実行できます。

#### 事前に必要なもの

- GitHubアカウント
- このリポジトリへの書き込み権限（ワークフローの実行に必要です）
- インターネットにつながるパソコン（Windowsでなくても構いません）

#### 実行する手順

1. ブラウザーでGitHubのリポジトリのページを開きます。
2. 画面上部のタブから「**Actions**」をクリックします。
3. 左側の一覧にある「**Build Windows exe**」をクリックします。
4. 右側に表示される「**Run workflow**」ボタンをクリックします。
5. 小さなパネルが開くので、ビルドしたいブランチ（通常は `main`）を選び、緑色の「**Run workflow**」ボタンをクリックします。
6. 数秒待って画面を再読み込みすると、一覧の先頭に黄色い印の付いた実行が現れます。これがビルド中の印です。
7. 3〜5分ほどで緑色のチェックに変われば成功です。

#### 成果物を受け取る

1. 完了した実行の行をクリックして、実行結果のページを開きます。
2. ページ下部の「**Artifacts**」の欄にある `OfficePdfConverter` をクリックすると、ZIPファイルがダウンロードされます。
3. ZIPファイルを右クリックして「すべて展開」を選び、中身を取り出します。

ZIPには次の2つが入っています。

- `OfficePdfConverter.exe` — 配布するexe本体
- `インストールマニュアル.pdf` — このマニュアル

あとは第1部の手順どおり、exeを配布先のパソコンへコピーするだけです。ダウンロードしたファイルにはWindowsが「他のパソコンから来たファイル」という印を付けることがあります。起動できない場合は第1部1-4を参照してブロックを解除してください。

成果物はGitHub上に90日間保存され、その後は自動的に削除されます。必要になったら、同じ手順でもう一度実行してください。

#### タグを付けてリリースとして配布する

`v` で始まるタグ（例: `v1.0`）をプッシュすると、ワークフローが自動で実行され、同じexeとPDFがGitHubの「Releases」へ添付されます。配布用のリンクを社内へ知らせたい場合に便利です。

```
git tag v1.0
git push origin v1.0
```

#### 困ったときは

- **「Run workflow」ボタンが表示されない** — ワークフローの定義ファイルがデフォルトブランチ（通常は `main`）に無いと、このボタンは表示されません。`.github/workflows/build-exe.yml` が `main` に取り込まれているか確認してください。
- **「Actions」タブが見当たらない** — リポジトリの設定でActionsが無効になっている可能性があります。「Settings」→「Actions」→「General」で有効にしてください。
- **実行が赤い×印で終わった** — 実行結果のページで失敗したステップをクリックすると、ログが開いて原因を確認できます。「exeをビルド」のステップで止まっている場合は、ソースコードか依存ライブラリ側の問題です。
- **成果物が見当たらない** — 実行が最後まで終わっていない可能性があります。緑色のチェックが付いてから確認してください。

### 2-3. 手元でビルドする場合に必要なもの

ここから先は、自分のパソコンでビルドする場合の手順です。2-2のGitHub Actionsを使う場合は読む必要はありません。ビルドは**Windows 10/11のパソコン**で行ってください。他のOSではWindows用exeを作れません。

- Windows 10 または Windows 11
- Python 3.10以降
- インターネット接続（ライブラリの取得に使用）
- ディスクの空き容量 約1GB

ビルドするパソコンにMicrosoft Officeは不要です。ただし、作ったexeの動作確認まで行う場合はOfficeが必要です。

### 2-4. Pythonをインストールする

すでにPython 3.10以降が入っている場合は、この手順を飛ばせます。コマンドプロンプトで `python --version` を実行すると確認できます。

1. ブラウザーで python.org のダウンロードページを開きます。
2. Windows用のインストーラー（64bit版）をダウンロードします。
3. インストーラーを実行し、最初の画面で **「Add python.exe to PATH」に必ずチェックを入れます**。ここにチェックを入れないと、後の手順で `python` コマンドが見つかりません。
4. 「Install Now」をクリックして完了させます。
5. インストール後、**コマンドプロンプトを開き直してから** `python --version` を実行し、バージョンが表示されることを確認します。

`tkinter` はWindows版のPythonに含まれているため、別途の導入は不要です。

### 2-5. ソースコードを用意する

リポジトリをクローンするか、ZIPでダウンロードして展開します。展開先のフォルダーには、`main.py` と `OfficePdfConverter.spec` が並んでいるはずです。

### 2-6. ビルド用の環境を作る

コマンドプロンプトまたはPowerShellを開き、ソースコードのフォルダーへ移動してから、順に実行します。

```
cd C:\path\to\2026-08_PptxToPdf
python -m venv .venv-build
.venv-build\Scripts\activate
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```

`activate` が成功すると、プロンプトの先頭に `(.venv-build)` と表示されます。PowerShellで「スクリプトの実行が無効」というエラーが出る場合は、コマンドプロンプトで同じ手順を実行してください。

### 2-7. exeをビルドする

同じウィンドウで次を実行します。

```
pyinstaller --noconfirm --clean OfficePdfConverter.spec
```

数分かかります。完了すると、次の場所にexeが作られます。

```
dist\OfficePdfConverter.exe
```

配布するのはこの1ファイルだけです。`build` フォルダーと `.venv-build` フォルダーは作業用なので配布しません。

### 2-8. 配布前の確認

作ったexeは、必ず次を確認してから配布してください。

1. Officeが入ったWindows 10/11のパソコンへexeをコピーする。
2. ダブルクリックし、コンソール画面が出ずにアプリだけが起動することを確認する。
3. PPTX・DOCX・XLSXを1つずつ実際にPDFへ変換できることを確認する。

組織外へ配布する場合は、exeへコード署名を行うとSmartScreenの警告が出にくくなります。

### 2-9. ビルドで困ったときは

#### `python` が見つからない

Pythonのインストール時に「Add python.exe to PATH」へチェックを入れ忘れています。インストーラーを再実行して「Modify」から追加するか、Pythonを入れ直してください。

#### `pip install` がネットワークエラーになる

社内プロキシ環境では、`pip` にプロキシの設定が必要な場合があります。情報システム部門へ確認してください。

#### ビルドは成功するがexeが起動しない

`build` と `dist` フォルダーを削除し、`--clean` を付けて再度ビルドしてください。それでも解決しない場合は、`OfficePdfConverter.spec` の `console` を一時的に `True` にしてビルドすると、コンソールにエラーが表示されて原因を調べられます。

## 付録 このマニュアルの作り直し方

このマニュアルの本文は `docs/install_manual.md` です。PDFは次のコマンドで作り直せます。

```
python -m pip install reportlab
python tools\make_manual.py
```

`docs\インストールマニュアル.pdf` が生成されます。PDFはリポジトリには含めていません（バイナリファイルを扱えない環境があるため）。
